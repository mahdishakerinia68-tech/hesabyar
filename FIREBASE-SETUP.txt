راهنمای فعال‌سازی همگام‌سازی دو گوشی برای حسابدار

1) وارد Firebase Console شو:
https://console.firebase.google.com/

2) یک Project جدید بساز.

3) از Project settings > Your apps > Web، یک Web App بساز و Firebase Config را بردار.
در برنامه، از تنظیمات > همگام‌سازی دو گوشی، این موارد را وارد کن:
apiKey
authDomain
projectId
storageBucket (اختیاری)
appId

4) از Authentication > Sign-in method، گزینه Email/Password را فعال کن.

5) از Firestore Database، دیتابیس بساز.

6) در Firestore Rules این قوانین را قرار بده:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

7) روی گوشی اول برنامه را باز کن:
تنظیمات > همگام‌سازی دو گوشی > تنظیم اتصال و ورود
اطلاعات Firebase را وارد کن.

اگر هنوز حساب نداری، ایمیل و رمز را وارد کن و «ساخت حساب همگام‌سازی» را بزن.

8) روی گوشی دوم همین فایل برنامه را نصب/باز کن، همان اطلاعات Firebase و همان ایمیل/رمز را وارد کن و «ذخیره و اتصال» را بزن.

از این به بعد اطلاعات حسابداری هر دو گوشی در مسیر users/{userId} در Firestore همگام می‌شود.

نکته مهم:
- apiKey مربوط به Firebase Web App به‌تنهایی رمز مخفی محسوب نمی‌شود؛ امنیت اصلی با Authentication و Firestore Rules است.
- هر دو گوشی باید اینترنت داشته باشند تا تغییرات لحظه‌ای همگام شوند.
- اگر هر دو گوشی دقیقاً همزمان یک رکورد را تغییر دهند، آخرین ذخیره ممکن است تغییر قبلی را جایگزین کند. برای استفاده معمولی و ثبت تراکنش‌ها این نسخه مناسب است؛ برای همگام‌سازی حرفه‌ایِ بدون تعارض باید داده‌ها به‌صورت رکوردبه‌رکورد پیاده‌سازی شوند.
- اطلاعات قبلی که فقط روی گوشی اول بوده، بعد از اولین اتصال به‌عنوان داده اولیه در فضای ابری ذخیره می‌شود.
