راهنمای فعال‌سازی همگام‌سازی همزمان دو گوشی برای حسابدار ۲.۱.۱

1) پروژه Firebase برنامه را استفاده کن یا یک پروژه جدید بساز.
2) در Authentication > Sign-in method، Email/Password را فعال کن.
3) در Firestore Database، دیتابیس بساز.
4) قوانین Firestore:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /records/{recordId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}

5) روی گوشی اول: تنظیمات > همگام‌سازی دو گوشی > ساخت حساب با ایمیل.
6) روی گوشی دوم: همان ایمیل و رمز را وارد کن و ورود با ایمیل را بزن.

نکات نسخه ۲.۱.۱:
- هر حساب، تراکنش، شخص، یادآوری، چک و دسته یک سند جداگانه دارد.
- تغییرات فقط برای رکوردهای تغییرکرده به Firestore ارسال می‌شوند؛ بنابراین دو گوشی تغییرات مستقل یکدیگر را overwrite نمی‌کنند.
- batchهای Firestore به قطعات کوچک‌تر از سقف ۵۰۰ عملیات تقسیم می‌شوند.
- حذف‌ها tombstone دارند تا رکورد حذف‌شده در دستگاه آفلاین دوباره ظاهر نشود.
- برای همگام‌سازی لحظه‌ای، هر دو گوشی باید اینترنت داشته باشند. Firestore تغییرات را با realtime listener به دستگاه‌های متصل می‌رساند و تغییرات آفلاین را بعد از اتصال مجدد همگام می‌کند.
