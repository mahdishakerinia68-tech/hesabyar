# 📒 حسابیار

اپلیکیشن حسابداری شخصی و کسبوکاری، کاملاً فارسی و راستبهچپ، بهصورت **PWA** (قابل نصب روی گوشی و بدون نیاز به اینترنت). تمام اطلاعات روی خود گوشی/مرورگر ذخیره میشود؛ همگامسازی ابری کاملاً اختیاری است.

> نسخه فعلی: **2.7.2**

---

## ✨ امکانات

### 💰 حسابها و تراکنشها
- تعریف نامحدود حساب بانکی/نقدی، ثبت موجودی اولیه و مشاهدهی موجودی لحظهای هر حساب
- ثبت تراکنش درآمد/هزینه با دستهبندی، توضیحات و پیوست چند-عکسی (تا ۵ عکس برای هر تراکنش)
- انتقال بین حسابهای خودم یا به شخص/کارت دیگر
- تراکنشهای تکرارشونده (روزانه/هفتگی/ماهانه) بهصورت خودکار
- خواندن و تفکیک خودکار پیامک بانکی برای ثبت سریع تراکنش
- جستوجو و فیلتر تراکنشها بر اساس نوع، دسته و بازهی تاریخ
- خروجی Excel از گردش هر حساب

### 🧾 فاکتور، مشتری و کالا
- صدور فاکتور فروش با اقلام، تخفیف و وضعیت پرداخت (کامل/بخشی/پرداختنشده)
- مدیریت مشتریان با صورتحساب و خروجی PDF/Excel
- انبار و کالا: قیمت خرید/فروش، موجودی، هشدار اتمام موجودی، گزارش سود کالا
- برندینگ فاکتور: نام فروشگاه، لوگو، مهر و امضا (+ ابزار بهبود خودکار تصویر لوگو/مهر)

### 👥 بدهکار / بستانکار
- ثبت بدهی یا طلب، یکجا یا **قسطی** (اقساط بهصورت خودکار ماهبهماه تقسیم میشود)
- تسویهی کامل یا پرداخت تکتک اقساط، با ثبت خودکار تراکنش و رسید
- هر سررسید (کلی یا هر قسط) هم در «جدول هفتگی» دیده میشود و هم یک **یادآوری واقعی با اعلان روی گوشی** برایش ساخته میشود؛ با پرداخت، خودش پاک میشود

### 💳 چکها
- ثبت چک دریافتنی/پرداختنی، هشدار سررسید نزدیک، ثبت نشستن/برگشت
- یادآوری خودکار چند روز مانده به سررسید

### 📝 یادداشت و یادآوری
- یادداشت با چکلیست آیتمهای ریز؛ با تیکخوردن هر آیتم، از لیست اصلی کنار میرود و زیر «تکمیلشده» جمع میشود تا شلوغ نشود
- یادآوریهای مستقل با تکرار یکبار/هفتگی/ماهانه و اعلان بومی (native notification)
- «جدول هفتگی»: نمای ۷ روزهی تقویم شمسی که یادداشت، یادآوری و سررسید بدهکار/بستانکار را کنار هم، مرتبشده بر اساس ساعت، نشان میدهد
- یادداشت هوشمند: تحلیل یک متن آزاد فارسی (با DeepSeek) و تبدیل خودکار به تراکنش/بدهی/یادآوری

### 📊 گزارش و داشبورد
- نمودار درآمد/هزینه، بیشترین دستههای هزینه، ماندهی هر حساب
- بودجهی ماهانه برای هر دستهی هزینه با هشدار عبور از سقف
- گزارش پیشرفته با فیلتر نوع/حساب/بازهی تاریخ
- کارتابل فعالیتها (Activity Log) برای پیگیری هر تغییر

### 🔒 امنیت و داده
- قفل ورود با رمز عددی یا الگو + قفل بیومتریک (اثر انگشت/چهره از طریق WebAuthn یا افزونهی بومی)
- پشتیبانگیری خودکار و دستی، بازیابی از فایل پشتیبان
- سطل زباله (Trash) برای بازگردانی موارد حذفشده
- همگامسازی ابری اختیاری با Firebase (بین چند دستگاه)

### 🎨 تجربهی کاربری
- کاملاً PWA: نصب روی گوشی، کار آفلاین، آیکون و اسپلش اختصاصی
- حالت شخصی / کسبوکاری / فروشگاه (کیوسک قفلشده با رمز ادمین جدا)
- تم روشن/تاریک + چند پالت رنگی قابل انتخاب
- طراحی بصری اختصاصی («دوات و مُهر») بهجای قالبهای تکراری رایج
- پشتیبانی از فارسی/انگلیسی و تقویم شمسی در همهجای برنامه

## 🛠 تکنولوژی

- HTML / CSS / **Vanilla JavaScript** (بدون فریمورک، بدون build step)
- ذخیرهسازی محلی: `localStorage`
- PWA: `manifest.json` + `sw.js` (Service Worker)
- همگامسازی ابری اختیاری: Firebase Firestore
- آماده برای بستهبندی به اپ اندروید با **Capacitor** (بریجهای بیومتریک، فایلسیستم و نوتیفیکیشن محلی از قبل در پروژه موجودند)

## 🚀 اجرا / انتشار

### اجرای محلی
هیچ ابزار یا نصبی لازم نیست؛ کافیست `index.html` را با یک وبسرور ساده سرو کنید (برای کارکرد صحیح Service Worker، بازکردن مستقیم فایل کافی نیست):

```bash
npx serve .
# یا
python3 -m http.server 8080
```

### انتشار رایگان با GitHub Pages
1. این مخزن را در گیتهاب push کنید.
2. در تنظیمات مخزن: **Settings → Pages → Branch: main / (root)** را انتخاب کنید.
3. بعد از چند دقیقه، آدرسی مثل `https://USERNAME.github.io/REPO-NAME/` فعال میشود.
4. کاربران با باز کردن این آدرس در مرورگر موبایل و زدن «افزودن به صفحهی اصلی»، اپ را مثل یک اپ نصبشده استفاده میکنند.

### بستهبندی به APK اندروید
پروژه از قبل شامل بریجهای Capacitor است. برای ساخت نسخهی اندرویدی:
```bash
npm install @capacitor/core @capacitor/android
npx cap init
npx cap add android
npx cap sync
npx cap open android   # ساخت APK از Android Studio
```

## 🔐 حریم خصوصی
تمام اطلاعات مالی بهصورت پیشفرض فقط روی همان دستگاه (`localStorage`) ذخیره میشود و به هیچ سروری ارسال نمیشود. همگامسازی ابری کاملاً اختیاری است و فقط با وارد کردن دستی تنظیمات Firebase توسط خود کاربر فعال میشود.
